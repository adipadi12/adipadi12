## 🛠️ What I'm Working On

### 🌐 Browser-Based Level Editor

A browser-based 3D level editor inspired by tools like Blender and Unity.

- **TypeScript**
- **React**
- **Three.js / React Three Fiber**
- Interactive scene editing
- Transform gizmos
- Scene hierarchy
- Object manipulation
- JSON scene serialization
- Eventually exporting scenes for use in Unity

🔗 [Repository](https://github.com/adipadi12/Browser-Level-Editor)

---

### 🎨 Custom Renderer

Building a renderer from scratch to better understand the fundamentals behind modern graphics APIs and game engines.

Currently exploring:

- Rendering pipelines
- OpenGL
- GLSL
- C++
- CMake
- Cameras & transformations
- Lighting
- Materials
- Textures
- GPU/CPU interaction

🔗 [Repository](https://github.com/adipadi12/OpenGL-Project)
